## Selection

Selected from the 15 fully accessible longer-running creatives in the current BigSpy account and search for `colony flow!` (exact search, Game, 2024-11-08 to 2026-11-08). This is not a verified global top 14 across all search results.

Each metric receives 25% weight, normalized to its maximum among the 15 candidates:

`score = 25 * (runningDays/61 + creativeScore/130000 + impressions/698000 + popularity/397)`

Figures are the rounded values displayed by BigSpy. Spend, clicks, CTR, conversions, CPA, CPI and ROAS were not available in the inspected Overview and Data Trends panels. Popularity is not interpreted as click count. These indirect signals do not establish profitability.
